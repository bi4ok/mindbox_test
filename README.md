# Задание №1
Напишите на C# или Python библиотеку для поставки внешним клиентам, которая умеет вычислять площадь круга по радиусу и треугольника по трем сторонам.

## Реализация:
1) В папке shapes файлы:
   - base_shape.py -> Интерфейс базовой фигуры
   - triangle.py -> реализация треугольника
   - circle.py -> реализация круга
2) Тесты в файле figure_test.py в папке tests (на unittest)

### Комментарии:
Захотелось реализовать методы расчётов так, чтобы их не вызывали повторно с одними и теми же значениями (без готового кэширования)

# Задание №2
В PySpark приложении датафреймами(pyspark.sql.DataFrame) заданы продукты, категории и их связи. Каждому продукту может соответствовать несколько категорий или ни одной. А каждой категории может соответствовать несколько продуктов или ни одного. Напишите метод на PySpark, который в одном датафрейме вернет все пары «Имя продукта – Имя категории» и имена всех продуктов, у которых нет категорий.

## Реализация:
Код лежит в файле "pyspark_task.ipynb"
Прописал сразу в ноутбуке, чтобы можно было легко посмотреть и код и результат запуска
